# 关于本项目

## 项目背景

本项目是湖北大学计算机学院 2026-2027 学年第一学期《开源软件设计与分析》课程的第二个实验。

## 实验目的

1. **GitHub Actions 使用**：创建工作流配置文件，触发运行并观察执行过程，验证成功执行
2. **GitHub Pages 使用**：用 Actions 实现 MkDocs 文档的自动构建与部署

## 技术栈

| 技术 | 版本 | 用途 |
|------|------|------|
| Python | 3.11 | 计算器模块 |
| pytest | latest | 单元测试 |
| MkDocs Material | latest | 文档站点主题 |
| GitHub Actions | - | CI/CD |
| GitHub Pages | - | 静态网站托管 |
